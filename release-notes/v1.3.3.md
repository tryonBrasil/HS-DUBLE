# HS Voice Translator 1.3.3

Correções baseadas na auditoria:

- Desativado o backup automático do Android para reduzir o risco de exposição da chave de API salva localmente.
- Corrigido o controle de volume da voz dublada para evitar aplicar o ganho duas vezes.
- Limitada a fila de áudio para evitar acúmulo de atraso.
- Corrigida a restauração do volume original quando o volume do sistema começa em zero.
- O verificador de atualizações ignora tags de Release inválidas.
- O CI valida o número da versão antes de publicar uma Release.

Esta versão precisa ser validada em dispositivo real, especialmente a qualidade do áudio e a atualização por cima da versão anterior.
